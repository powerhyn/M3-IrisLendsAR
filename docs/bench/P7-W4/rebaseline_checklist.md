# P7-W4 재베이스라인 체크리스트 (코드 작성 전 — §5.7)

> 목적: W9 흰자 빛남 관측(W2 교정 **이전**)의 현재 잔존 강도 확인. 결과가 W4 진행/조기 종결을 결정.
> 기기: S23+ (SM-S916N), APK **b292** (2026-06-10 설치, develop = W2 실측 default ON 상태)
> 평가: 본인 실시간 토글 체감 (`solo-dev-bench-method`). 정량 수치 기준 없음.

## 배경 (왜 두 조명 조건인가)

scale 포화 경계 avgLum ≈ **0.121** (= 0.85/7.0). W2 실측: 정적 실내 ema≈0.067 / 밝게 비추면 ≈0.6.

- **일반 실내**: avgLum < 0.121 → scale 여전히 clamp 7.0 = **W9 관측 조건과 동일** → 빛남 잔존 예상
- **밝은 조명**: avgLum ≈ 0.6 → scale ≈ 1.27 (W2 교정 적용) → 빛남 완화됐을 가능성

## 절차

GpuRenderActivity 진입 → 블렌드 TintLinearV2(ID=5, 기본) 확인 → SKU 선택 → 조명 조건별 관찰.

토글: **`lum:meas`**(기본, 실측) ↔ **`lum:fb`**(fallback = W9 당시 조건 재현). 토글 비교로 "W2 교정이 빛남에 준 변화"를 같은 자리에서 즉시 확인.
