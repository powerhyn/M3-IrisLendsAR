# P6-W4 평가 응답 시트 — 컬럼 의미

`ratings_template.csv` 작성 가이드. W4 §5.2 메트릭 기반.

| 컬럼 | 의미 | 입력 |
|------|------|------|
| `clip_id` | 무작위 클립 ID | (사전 채워짐, 변경 금지) |
| `rater_id` | 평가자 ID (R1/R2/R3) | (사전 채워짐) |
| `naturalness_1to5` | **자연스러움 선호도** (양성, 1순위 메트릭) | 1=매우 부자연 / 5=매우 자연 |
| `center_glare_y_n` | iris 중앙에 부자연스러운 반짝이 있나? (음성) | Y=있음 / N=없음 |
| `face_reflect_y_n` | 얼굴 재귀 반사처럼 보이나? (음성, Codex 우려) | Y / N |
| `asymmetry_y_n` | 좌우 눈 반사 불일치 보이나? (음성) | Y / N |
| `env_disconnect_y_n` | 환경과 무관해 보이나? (음성, Gemini 우려) | Y / N |
| `pupil_cavity_y_n` | **중앙 공동(cavity) 체감?** (음성, P6-W8 발동 판정) | Y / N |
| `free_note` | 자유 기술 (1줄, 선택) | 텍스트 |

## 작성 원칙 (평가자에게 사전 안내)

1. **블라인드 평가** — 어떤 프로토타입(OFF/EnvMap/Periphery)인지 모르는 상태에서 평가.
2. **재생 환경 통일** — 동일 디바이스/화면 밝기. 가능하면 같은 방에서.
3. **한 클립 5초 trim 길이** — 같은 클립을 여러 번 봐도 됨.
4. **자유 기술은 1줄** — 길게 적지 말 것. 평가 일관성 우선.

## 판정 룰 (W4 §5.2 / §5.6)

- **자연스러움 1순위**: 24 클립 평균 점수로 프로토타입(P0/P1/P2) 순위.
- **음성 메트릭**: 평가자 3명 중 2명 이상 Y면 그 프로토타입에 마이너스.
- **Pupil cavity 2/3 룰**: 
  - 3명 중 2명 이상 Y → **P6-W8 착수**
  - 3명 모두 N → P6-W8 폐기
  - 1명만 Y → **사용자 최종 판단**
