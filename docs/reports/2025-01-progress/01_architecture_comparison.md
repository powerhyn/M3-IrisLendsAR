# IrisLensSDK 아키텍처 및 솔루션 비교

## 1. 개요

IrisLensSDK는 실시간 카메라 영상에서 홍채를 추적하여 가상 렌즈를 오버레이하는 AR 피팅 SDK입니다.

### 핵심 목표
- **실시간 처리**: 30fps 이상의 부드러운 렌즈 피팅
- **크로스플랫폼**: Android, iOS, Flutter, Web 지원
- **온디바이스 처리**: 개인정보 보호를 위한 로컬 처리

## 2. 아키텍처

### 2.1 전체 구조

```
┌─────────────────────────────────────────────────────────┐
│                    Application Layer                     │
│              (Android App / iOS App / Flutter)           │
└─────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────┐
│                    Platform Binding                      │
│           (JNI / Objective-C++ / dart:ffi)              │
└─────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────┐
│                   IrisLensSDK Core                       │
│       ┌─────────────┐       ┌─────────────┐             │
│       │ Iris        │       │ Lens        │             │
│       │ Detector    │       │ Renderer    │             │
│       └─────────────┘       └─────────────┘             │
└─────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────┐
│                    AI/ML Engine                          │
│         (MediaPipe Face Mesh + Iris Landmark)           │
└─────────────────────────────────────────────────────────┘
```

### 2.2 처리 파이프라인

```
카메라 프레임 입력 (YUV)
        │
        ▼
┌───────────────────┐
│  얼굴 검출        │  ← MediaPipe Face Mesh
│  (478 랜드마크)   │
└───────────────────┘
        │
        ▼
┌───────────────────┐
│  홍채 추적        │  ← MediaPipe Iris Landmark
│  (중심점 + 반경)  │
└───────────────────┘
        │
        ▼
┌───────────────────┐
│  스무딩 필터      │  ← One-Euro Filter (지터 방지)
└───────────────────┘
        │
        ▼
┌───────────────────┐
│  렌즈 렌더링      │  ← 투명 PNG 오버레이
└───────────────────┘
        │
        ▼
    화면 출력
```

### 2.3 핵심 기술

| 기술 | 설명 | 용도 |
|------|------|------|
| MediaPipe | Google의 ML 프레임워크 | 얼굴/홍채 검출 |
| TensorFlow Lite | 경량 ML 추론 엔진 | 온디바이스 AI |
| OpenCV | 컴퓨터 비전 라이브러리 | 이미지 처리, 뷰티 필터 |
| One-Euro Filter | 적응형 노이즈 필터 | 좌표 안정화 |

## 3. 솔루션 비교

### 3.1 비교 대상

| 솔루션 | 유형 | 주요 사용처 |
|--------|------|-------------|
| **IrisLensSDK (자체 개발)** | 인하우스 SDK | 자사 앱 전용 |
| **Flutter MediaPipe** | 오픈소스 플러그인 | Flutter 앱 |
| **Perfect Corp (YouCam)** | 상용 SDK | 뷰티/패션 브랜드 |
| **ModiFace (L'Oreal)** | 상용 SDK | 화장품 브랜드 |
| **Banuba** | 상용 SDK | AR 이펙트 |

### 3.2 상세 비교

#### IrisLensSDK (자체 개발)

**장점**
- ✅ **완전한 커스터마이징**: 모든 기능을 자사 요구에 맞게 조정 가능
- ✅ **라이선스 비용 없음**: 외부 SDK 사용료 없음
- ✅ **데이터 보안**: 외부 서버 의존 없이 온디바이스 처리
- ✅ **독점 기술**: 경쟁사 대비 차별화된 기능 구현 가능
- ✅ **장기적 비용 효율**: 초기 개발 후 유지보수 비용만 발생

**단점**
- ⚠️ **초기 개발 비용**: 개발 인력 및 시간 투자 필요
- ⚠️ **기술 부채 관리**: 지속적인 유지보수 필요
- ⚠️ **신기술 적용 지연**: 외부 SDK 대비 신기술 도입 속도 느림

---

#### Flutter MediaPipe (Google 플러그인)

**장점**
- ✅ 무료 오픈소스
- ✅ Google 지원 및 커뮤니티
- ✅ Flutter 네이티브 통합

**단점**
- ❌ **홍채 전용 기능 부재**: 일반 Face Mesh만 제공
- ❌ **렌즈 렌더링 없음**: 피팅 기능 직접 구현 필요
- ❌ **성능 제한**: Flutter 레이어 오버헤드
- ❌ **커스터마이징 제한**: Google 정책에 의존

---

#### 상용 SDK (Perfect Corp, ModiFace, Banuba)

**장점**
- ✅ 즉시 사용 가능한 완성도
- ✅ 다양한 AR 이펙트 내장
- ✅ 기술 지원 및 업데이트

**단점**
- ❌ **높은 비용**: 월/연 구독료 또는 MAU 기반 과금
  - Perfect Corp: 월 $1,000~$10,000+
  - Banuba: MAU당 $0.01~0.05
- ❌ **데이터 우려**: 일부 SDK는 서버 전송 필요
- ❌ **종속성**: 외부 업체 정책 변경에 취약
- ❌ **차별화 어려움**: 경쟁사도 동일 SDK 사용 가능

## 4. 자체 개발 선택 이유

### 4.1 비즈니스 관점

1. **장기 비용 효율성**
   - 상용 SDK 연간 비용: $12,000~$120,000+
   - 자체 개발 후 유지보수 비용: 개발자 인건비만

2. **차별화된 사용자 경험**
   - 자사 렌즈 제품에 최적화된 피팅 알고리즘
   - 경쟁사와 동일 SDK 사용 시 차별화 불가

3. **데이터 주권**
   - 사용자 얼굴 데이터 외부 유출 차단
   - 개인정보보호법 준수 용이

### 4.2 기술 관점

1. **MediaPipe 기반의 검증된 AI**
   - Google이 개발한 고성능 ML 프레임워크
   - 지속적인 업데이트 및 최적화

2. **크로스플랫폼 아키텍처**
   - C++ 코어로 모든 플랫폼 지원
   - 플랫폼별 최적화 가능

3. **확장성**
   - 뷰티 필터, AR 이펙트 등 기능 확장 용이
   - 자사 요구에 맞는 신기능 즉시 개발 가능

---

## 5. 결론

IrisLensSDK 자체 개발은 **초기 투자가 필요하지만**, 장기적으로 **비용 효율성**, **기술 독립성**, **차별화된 사용자 경험**을 제공합니다.

특히 렌즈 피팅이라는 특화된 기능에서는 상용 SDK의 범용 기능보다 **자사 제품에 최적화된 솔루션**이 더 높은 가치를 제공합니다.
