# P6-W6 브레인스토밍 — Codex 의견

대상: `docs/workPaper/P6-W6_temporal_detail_bench.md` §6.1 ~ §6.7

전제: **B5/B9/C10 동시 수행은 타당**하다. 같은 저조도 블링크 시나리오에서 함께 캡처하되, **B5 판정과 B9 판정은 독립**으로 유지한다.

## 6.1 EMA α → ms 공식 정확도

- 추천: **`computeEmaAlpha(target_ms, fps) = 1 - pow(0.05, dt / target_ms)`를 그대로 쓰고, `fps`는 고정 30 가정이 아니라 실측 `dt`/실기기 로그 기준으로 넣는다**.
- 근거: Codex R3가 지적한 문제는 "목표 ms와 α가 안 맞는다"였으므로 근사식이 아니라 정밀식을 써야 한다. 실기기 프레임레이트 변동까지 반영해야 60/80/120ms 목표가 실제로 맞는다.

## 6.2 B5 user 수 축소

- 추천: **3명 × 5 블링크 × 3 시간 = 45 이벤트로 축소 허용**.
- 근거: Phase 6 벤치의 판정 원칙은 통계 검정보다 정성 체감 기반 다수 의견이다. B5도 "팝"과 "늦게 나타남" 체감 비교가 핵심이라 3명 규모면 충분하다.

## 6.3 B9 gate smoothstep 경계값

- 추천: **`GATE_LOW = threshold - 0.03`, `GATE_HIGH = threshold + 0.03`**.
- 근거: B9는 본질적으로 임계값 하나를 고르는 벤치이므로 smoothstep 폭은 좁고 대칭적인 고정 오프셋이 맞다. ±0.03 정도면 gate가 계단처럼 끊기지 않으면서도 threshold 의미를 흐리지 않는다.

## 6.4 디테일 재주입 blur 커널 크기

- 추천: **3x3 유지**.
- 근거: C10의 목적은 원본 홍채 구조를 가볍게 되살리는 것이지 별도 고품질 블러 패스를 만드는 게 아니다. 5x5는 비용만 늘고, 2-pass는 single-pass 원칙과 충돌한다.

## 6.5 innerMask 경계

- 추천: **hard cutoff 대신 `smoothstep(0.7, 0.5, dist)` 같은 부드러운 innerMask를 쓴다**.
- 근거: `dist`는 이미 정규화된 값이라 이 범위면 `r<0.65` 의도를 충분히 근사하면서 경계 링이 덜 생긴다. hard mask는 디테일 재주입 경계가 눈에 띄어 림발 근처 이음새를 만들기 쉽다.

## 6.6 저조도 환경 정의

- 추천: **저조도는 고정 장면명보다 `avg_iris_luma` 기준으로 정의하고, B9의 threshold 후보(0.10/0.15/0.25)가 이 질문에 직접 답하게 둔다**.
- 근거: 같은 "실내"라도 조도 편차가 커서 환경 이름만으로 gate 판단을 일반화하기 어렵다. B9는 결국 `uAvgIrisLum` 경계를 고르는 벤치이므로 입력 정의도 그 값 기준이 맞다.

## 6.7 B5/B9 동시 측정 가능성

- 추천: **가능하다. 저조도 환경에서 블링크 반복으로 한 번에 캡처하되 B5와 B9 판정표는 분리한다**.
- 근거: B5는 temporal 반응, B9는 저조도 디테일 노이즈를 보므로 같은 클립을 재활용할 수 있다. C10도 이 둘의 결과를 흡수하는 구현 항목이라 W6에서 함께 묶는 편이 자연스럽다.
