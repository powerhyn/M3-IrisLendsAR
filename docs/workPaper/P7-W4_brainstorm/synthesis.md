## 6.2 다수결 상세 (유일한 2/3)

- **다수 (Codex + Claude)**: (c) 유효 틴트 배율 상한. 구현형까지 독립 수렴:
  ```glsl
  float tintMul = min(lum * scale, uScleraTintMax);   // 초기 cap = 0.85 * 1.5 ≈ 1.275
  vec3 tinted = toLinearFast(blend) * tintMul;
  ```
  근거 공통: 빛남 원인(`lum` 무상한, `shader_sources.cpp:877-880`)의 직접 차단 + brightness-invariant 의도 보존 + CRL detail clamp(`:889`)와 동형 패턴 + 파라미터 1개(cap)로 변수 최소화 — §6.3 임계·§6.7 메타 쟁점이 연쇄 소멸.
- **소수 (Gemini)**: (a) smoothstep 감쇄 — "(b)/(c) 하드 클램프는 고대비 경계에서 부자연스러운 계단 현상 유발 가능, (a)가 부드럽게 조절".
- **소수 의견 기술 검토**: `min()`은 값 연속(C0) — 픽셀 값 계단(banding)은 발생하지 않고 기울기 불연속(C1)뿐. 단 **"cap 도달 영역의 틴트 평탄화"가 시각적으로 거슬릴 가능성은 실재** → 기각이 아니라 **검증 항목으로 수용**: 토글 벤치 체크리스트에 "sclera 경계 평탄화/칙칙함 육안 확인" 추가 (Codex 6.5 단서와 동일 항목).
- **판정**: (c) 채택 제안. 1차 벤치에서 경계 부자연 확인 시 (a) smoothstep을 cap 위에 soft-knee로 추가하는 절충 경로 보존 (Gemini 안이 폐기가 아니라 fallback).

## 검증된 코드/데이터 사실 (3모델 인용 → Claude 직접 확인)

1. **모든 코드 인용 라인 일치 확인** — `shader_sources.cpp:875-882`(TintLinearV2), `:885-892`(CRL detail clamp), `:1011-1036`(geometry veto, finalAlpha), `:1042`(maxDetail), `:1057-1063`(블렌드 분기), `:1134`(post-blend 불가 근거), `gpu_lens_renderer.h:241-242`(veto 기본 ON/legacy 0), W9 report `:75-90`(빛남 패턴) — 전부 정확.
2. **Gemini 인용 오기 1건**: "scale 7.0→1.27 교정 (W2 §1.6)" — 해당 사실의 실제 출처는 **W2 §4.1** (W4 doc §1.6이 재인용). 사실 자체는 정확, 포인터만 오기.
3. ⚠️ **6.1 기대치 조정 데이터 (종합 단계 발견)**: W2 실기기 실측에서 **정적 실내 ema≈0.067, 밝게 비추면 ≈0.6** (W2 §4.1 DoD). scale 포화 경계는 avgLum = 0.85/7.0 ≈ **0.121** → **짙은 홍채 + 일반 실내 조명(한국 주 사용 시나리오)에서는 W2 교정 후에도 여전히 clamp 7.0 영역** = W9 빛남 관측 조건과 동일할 가능성. "조기 종결" 기대는 밝은 조명 한정으로 낮춰야 함. 3모델 중 Gemini가 "어두운 홍채 영역에서만 두드러질 가능성"으로 가장 근접했으나 수치 경계는 누구도 명시 안 함. → **재베이스라인은 밝은 조명 + 일반 실내 두 조건 모두 필요** (단, 저조도는 범위 외 유지 — `low-light-usage-rare`).
