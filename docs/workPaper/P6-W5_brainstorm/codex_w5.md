# P6-W5 브레인스토밍 — Codex 의견

대상: `docs/workPaper/P6-W5_blend_sclera_bench.md` §6.1 ~ §6.7

전제: **B1/B8 판정은 독립**으로 유지한다. **조합형 캡처 전략은 타당**하되, 캡처만 같이 하고 해석은 B1과 B8을 분리해서 한다.

## 6.1 SKU 중복 사용 여부

- 추천: **별도 SKU 확보**.
- 근거: B1은 스타일 셀 커버리지가 목적이라 `다크브라운`과 `불투명 서클`을 같은 SKU로 겸용하면 한 셀을 비우게 된다. 가능하면 `로뮤_디어 멜로우`와 `클라셋_돌 초코`를 분리하는 편이 맞다.

## 6.2 B1과 B8 동시 캡처 조합 라벨링

- 추천: **A/B/C/D 블라인드 라벨로 같은 take에서 4조합을 캡처**한다.
- 근거: 같은 동작/조명에서 `Normal+color`, `Normal+luma`, `CRL+color`, `CRL+luma`를 연속 토글하면 촬영 변수를 줄일 수 있다. 단 판정표에서는 B1 점수와 B8 점수를 따로 적어 독립 해석을 보장해야 한다.

## 6.3 CRL `detail` clamp 범위 재확인

- 추천: **`clamp(..., 0.75, 1.25)` 유지, `uMaxDetail` 기본값도 1.25 유지**.
- 근거: 이 범위가 99/C4와 W2 canonical 수식에 맞는 현재 기준값이라 W5의 질문은 먼저 `Normal vs CRL` 자체를 닫는 데 집중해야 한다. 상한까지 같이 바꾸면 B1이 모드 비교가 아니라 튜닝 비교로 흐려진다.

## 6.4 B1에서 "조건부 채택" 결과 시 구현

- 추천: **내부 SKU 메타데이터 `prefers_crl` 플래그로 자동 선택하고, W5에서는 공개 UI/공개 API 오버라이드는 넣지 않는다**.
- 근거: 99의 다른 메타 플래그(`has_baked_limbal`)와 같은 패턴이 가장 자연스럽다. 조건부 채택은 특정 SKU 셀에만 CRL을 쓰자는 뜻이지 사용자에게 새 모드 선택 책임을 넘기자는 뜻이 아니다.

## 6.5 Gemini luma-only 임계값 재확인

- 추천: **`smoothstep(0.45, 0.65, lum)` 그대로 유지**.
- 근거: B8은 우선 `sat 항 유무`를 비교하는 벤치라 lum 임계값까지 동시에 바꾸면 변수 분리가 안 된다. 저조도 재튜닝은 luma-only가 이긴 뒤 후속 미세조정으로 미루는 편이 맞다.

## 6.6 calcScleraFactor 기존 구현과 새 수식의 관계

- 추천: **함수명은 유지하고 내부 수식만 교체**한다.
- 근거: W5의 쟁점은 호출 구조가 아니라 veto 수식 자체라서 호출부를 흔들 이유가 없다. 벤치 중에도 같은 진입점에서 mode만 바꾸는 편이 비교와 반영이 단순하다.

## 6.7 color-veto 수식의 Codex 의도 재확인

- 추천: **`0.6`은 유지하고 W5 1차 판정에서는 튜닝하지 않는다**.
- 근거: `0.6`은 color-veto가 감쇄를 얼마나 되돌릴지 정하는 강도 계수이지 불변 상수는 아니지만, B8의 핵심은 `color-veto vs luma-only` 구조 비교다. 이 단계에서 0.6까지 움직이면 수식 구조와 강도 조절이 섞여 판정이 흐려진다.
