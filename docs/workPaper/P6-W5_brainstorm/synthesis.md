## 2. 다수결 / 절충

### 6.5 Gemini luma-only 임계값 — **`smoothstep(0.45, 0.65, lum)` 유지 (Codex+Gemini 2/3)**
- Codex: 유지 (B8 1차 변수 분리).
- Gemini: 유지, 저조도 결과에 따라 0.3~0.5로 하향 검토.
- Claude: 0.35/0.60 조정 제안.
- **판정:** **Claude 편향 정정** — 다수 2/3이 "W5 1차에서 임계값 튜닝 금지"에 수렴. B8은 `sat 항 유무`(color vs luma) 비교이고 임계까지 바꾸면 변수 분리 안 됨. 임계 조정은 1차 결과 "luma-only 채택" 시 후속 W에서.

### 6.7 color-veto `0.6` 튜닝 — **W5 1차: 0.6 고정, 2차/후속: [0.4, 0.8] 스위프 여지 (Codex 절차 + Gemini/Claude 여지 절충)**
- Codex: 0.6 고정, W5 1차 튜닝 금지 (변수 분리).
- Gemini: 0.6 시작, 0.4~0.8 튜닝 여지.
- Claude: 0.6 기본, 대표 SKU에 스위프.
- **판정:** **Codex 절차 수용** (1차 변수 분리). **튜닝은 1차 결과 후** — 쓰는 경우:
  - B8 1차 결과가 "color-veto 채택": W5 1차 종료 후 동일 W 내 **phase-2**에서 대표 SKU 2종에 0.4/0.6/0.8 스위프 (Claude 제안).
  - B8 1차 결과가 "luma-only 채택": color-veto 튜닝 자체가 불필요 → skip.
