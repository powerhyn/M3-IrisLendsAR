# Gemini의 P6-W5 브레인스토밍: 블렌드 및 공막 Veto 벤치 권고안

**작성일**: 2026-04-24
**대상**: docs/workPaper/P6-W5_blend_sclera_bench.md §6

## 1. 미결 사항에 대한 입장 및 권고

### 6.1 SKU 중복 사용 여부
*   **추천**: **별도 SKU 확보 (로뮤_디어 멜로우 및 클라셋_돌 초코 각각 사용)**
*   **근거**: '불투명 서클'과 '자연스러운 브라운'은 그래픽 밀도와 외곽선 처리가 다르므로, 블렌드 모드별 디테일 보존 능력을 정확히 평가하기 위해 중복 대신 별도 SKU 사용이 필요함.

### 6.2 B1과 B8 동시 캡처 조합 라벨링
*   **추천**: **A/B/C/D 블라인드 라벨링 방식**
*   **근거**: 평가자가 선입견 없이 순수하게 시각적 품질만을 비교할 수 있도록 하며, 4가지 조합(Normal/CRL × color/luma)을 효율적으로 관리할 수 있는 최선의 방법임.

### 6.3 CRL detail clamp 범위 (0.75, 1.25)
*   **추천**: **상한 1.25 및 하한 0.75 유지**
*   **근거**: 화이트/그래픽 렌즈에서 홍채 디테일이 렌즈를 뚫고 나오는 강도를 결정하는 핵심 범위로, 0.7 exponent와의 정합성을 벤치마크에서 우선 검증해야 함.

### 6.4 조건부 채택 구현 (SKU metadata 플래그)
*   **추천**: **SKU Metadata `prefers_crl: true` 플래그 방식**
*   **근거**: 특정 특수 SKU에서만 CRL이 우세할 경우, 전체 SDK 구조를 복잡하게 만들기보다 데이터 기반의 자동 전환을 통해 사용자 편의와 품질을 동시에 잡을 수 있음.

### 6.5 Gemini luma-only 임계값 (0.45, 0.65)
*   **추천**: **(0.45, 0.65) 초기값 유지 후 저조도 결과에 따라 하향 검토**
*   **근거**: Codex 수식과의 비교를 위해 동일한 기준점을 사용하되, 저조도 시나리오에서 홍채 외곽 무늬가 과도하게 깎이는 현상이 발견되면 0.3~0.5 수준으로 조정을 고려함.

### 6.6 calcScleraFactor 기존 구현과의 관계
*   **추천**: **함수 명칭 유지 및 내부 수식 전면 교체**
*   **근거**: SDK 내부 호출부의 인터페이스 수정을 방지하여 아키텍처 안정성을 유지하면서도, Phase 6에서 합의된 geometry-first 로직으로의 깔끔한 전환이 가능함.

### 6.7 color-veto 0.6 강도 튜닝 가능성
*   **추천**: **0.6 고정값으로 시작하되 0.4~0.8 범위 튜닝 가능성 열어둠**
*   **근거**: 0.6은 Codex가 제안한 Veto(감쇄 해제)의 기본 강도로서, 벤치마크 시 흰자 번짐 억제력과 조명 변화 대응력 사이의 균형점을 찾기 위한 기준값으로 적절함.

## 2. 벤치마크 전략 타당성 평가

1.  **B1/B8 독립 판정**: 매우 타당함. 블렌드 수식(재질)과 공막 Veto(기하학적 마스킹)는 서로 다른 렌더링 단계에서 작동하는 변수이므로, 각 항목에 대해 최적의 안을 독립적으로 선정하여 조합하는 것이 논리적임.
2.  **조합형 캡처 타당성**: 매우 타당함. 단일 촬영 세션에서 4가지 변수(A/B/C/D)를 동시 비교함으로써 촬영 리소스를 절감하고, 동일한 조명/포즈 조건하에서 변수 간 차이를 정교하게 대조할 수 있어 판정의 신뢰도가 극대화됨.
