# Codex R4 Patch Review

## Patch 1 (벤치 메트릭 정량→정성)
찬성 — 렌즈 자연스러움은 실패 카운트보다 블라인드 체감 비교가 더 맞다. 환경·조명·동작 커버리지를 우선한다는 방향도 B2 성격에 맞다.

## Patch 2 (B2 Pupil cutout 지표)
찬성 — 구현 채택이 아니라 체감 지표 추가이므로 반대할 이유가 없다. 20/20 중심 투명 실측과 Gemini 우려를 검증 항목으로만 두는 건 안전하다.

## Patch 3 (P6-W1 조건부 트랙)
찬성 — W3-05 즉시 포함이 아니라 B2 체감 조건부라서 내 R3 입장과 충돌하지 않는다. Option A(baseLum 하한) 기각도 내 우려와 맞다.

## Patch 4 (C5 renderMask hook)
중립 — 현재 동작이 `finalAlpha`와 동일하고 컴파일 타임 비활성 hook이면 hard veto는 없다. 단 주석 안의 `smoothstep` 수식은 최종 구현 수식으로 확정하면 안 된다.

## Patch 5 (텍스처 크기 256×256 공식 기재)
찬성 — 15번 실측의 표시 영역/메모리 계산상 256 기본, 512 HIGH 옵션이 합리적이다. 1000 원본은 공급 원본으로만 유지하는 판단도 맞다.

## Patch 6 (§6 미결 표 갱신)
찬성 — Patch 3과 문서 정합성을 맞추는 변경이다. Pupil cutout을 조건부 트랙으로 명시하는 편이 R3의 "Phase 6 이월 + 사용자 판단 여지"보다 선명하다.
