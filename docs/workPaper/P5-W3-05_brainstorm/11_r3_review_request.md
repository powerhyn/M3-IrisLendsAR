## 0. 왜 R3인가

R2까지는 각 모델이 **자기 입장**을 냈고, Claude가 그걸 모아 수렴 판단을 내려 `99_claude_synthesis.md`를 작성했다. 문제는:

1. **Codex와 Gemini는 이 종합 문서를 보지도 못했다.** 자기 R2 입장이 Claude 종합에 어떻게 반영됐는지 모른다.
2. **"합의됐다"라는 판단이 Claude 관점**이다. 세 모델이 실제로 "우리 이 결정에 합의한다"고 서로 확인한 적 없다.
3. **"벤치 이관"으로 분류된 4쟁점(I1/I2-잔여/I4/I8)**도 Claude가 결정한 것이지, 세 모델 합의로 벤치 이관된 것은 아니다.

이 라운드의 목표: **Claude의 종합 판단에 대한 독립적 검증**.

## 4. 규칙

1. **자기 R2 입장과 Claude 종합이 다르면 반드시 지적하라.** 얼버무림 금지.
2. **Claude가 "합의"라 분류한 것에 동의 안 하면 반드시 반대 의견을 쓰라.** 침묵은 동의로 간주되지 않는다.
3. **새 아이디어 제안 금지.** 이 라운드는 **Claude 종합에 대한 검증**이지, 새 대안을 꺼내는 라운드가 아니다. 자기 R1/R2에서 이미 제시한 논리를 **재강조**하거나, Claude 종합의 **왜곡/누락**을 지적하는 데만 집중.
4. **"벤치 이관" 결정에 반대한다면 R3 내에서 결론을 낼 수 있는 근거를 제시하라.** 없으면 벤치 이관 승인.
5. **Claude의 편향 가능성 지적 환영.** Claude는 Codex 논리에 9/10 쟁점에서 동조했는데, 이게 정당한 판단이었는지 Codex 본인과 Gemini가 평가하라. Gemini 관점에서 Claude가 Codex에 과도하게 쏠렸다면 지적.
6. 한국어. 코드는 GLSL ES 3.1.
