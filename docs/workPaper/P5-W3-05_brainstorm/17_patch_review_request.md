## 0. 이 라운드의 목적과 규칙

이 라운드는 **새 브레인스토밍 아님**. `99_final_decision.md`에 적용할 6개 수정안이 아래 근거에서 타당한지 **찬성/반대/중립 판정**만 요구.

### 규칙

1. 응답 파일:
   - Codex → `18_codex_r4_patch.md`
   - Gemini → `19_gemini_r4_patch.md`
2. **각 수정안에 대해 찬성/반대/중립 중 하나**만 명시하고 근거 1~2줄.
3. **"강한 반대(hard veto)"는 명확히 표시**. 미니 수정 제안이나 선호도 수준은 "중립" 또는 "찬성(단서부)"로.
4. **새 아이디어 금지**. 6개 수정안의 타당성만 판정.
5. 사용자 판정 기준: **어느 수정안에 대해서도 한 모델이라도 hard veto 없으면 전체 채택**. 단순 선호/중립은 채택 방해 않음.

### 필수 맥락 읽기

- `99_final_decision.md` — R3 합의본
- `15_asset_analysis.md` — 에셋 실측 결과
- `16_product_crosscheck.md` — 웹 교차검증 (보정 리스크 명시 포함)

## 1. 수정 내역 6개

### Patch 1 — §2 벤치 메트릭 톤 변경 (정량 → 정성 체감)

**Before** (R3 합의본):
> 판정 메트릭 (실패 카운트, 낮을수록 좋음): ...

**After**:
> 판정은 **정성적 체감 기반 블라인드 비교**로 진행. 숫자 카운트보다 **다양한 환경·조명·동작 커버리지**를 우선한다. 평가자 3명이 각 클립에 대해 (a) 자연스러움 선호도, (b) 언급할 만한 위화감 항목 자유 기술. 다수 의견 기반 판정.

**근거**: 사용자 지시 — "수치로 정량적으로 비교하기보단 실제 여러 환경에서 렌더링되는 것을 눈으로 확인하고 체감해야 알 수 있는 부분".

**찬성/반대/중립 판정 부탁**.

### Patch 2 — §2 B2 (환경 반사 벤치)에 "Pupil cutout 체감 지표" 추가

**추가 지표**: "**중앙 공동(cavity) 체감** — 밝은 렌즈 × 짙은 홍채 조합(특히 엔비_퍼퓸글로우, 클라셋_런웨이그레이 × 아시아 짙은 홍채)에서 렌즈 중앙이 '구멍 뚫린 느낌'으로 보이는지 Y/N 체크".

**근거**: 15/16 분석에서 20/20 렌즈 전부 중앙 완전 투명 확인. Gemini R2/R3에서 "경쟁사 대비 가장 큰 약점" 지적. P6-W1 조건부 트랙 착수 조건을 이 지표로 판정.

**찬성/반대/중립 판정 부탁**.

### Patch 3 — §4 Phase 6 이월의 Pupil cutout 행 → **P6-W1 조건부 트랙**

**Before** (R3):
> "Pupil cutout 동적 처리 (baseLum 하한 강제) — R3 미합의 (2 vs 1 Phase 6 이월)"

**After**:
```
P6-W1 (조건부 트랙) — Pupil cutout 해결

해결 방향: Option E "렌즈 재질 반투명 복원"
  - 원본 홍채 건드리지 않고, 렌즈 자체의 재질감(반투명+광택)을
    동공 영역에도 옅게 확장하는 방식
  - Option A(baseLum 하한)는 홍채 디테일 훼손 리스크로 기각
  - 사용자 실물 관찰: 실제 렌즈 중앙 감도는 재질 특성이며
    눈물막과 결합해 자연 투명해짐. W3-05 환경 반사 인프라로
    자연 커버 가능성 있음

착수 조건 (Hard):
  - B2 벤치에서 평가자 3명 중 2명 이상 "중앙 공동 체감"이면 P6-W1 착수
  - 모두 "체감 없음"이면 P6-W1 폐기 (자연 커버 성공)
  - 1명만 체감 시 사용자 판단

인프라: W3-05 C5 renderMask hook (Patch 4 참조)이 기본 구조 준비
```

**근거**: 사용자 실물 관찰("알파 그라디언트 의도 아닌 재질 감도, 눈물막과 결합해 자연 투명") + "의도적으로 뭔가 안 해도 될 수 있다" 입장. 즉 **새 코드 추가 전 기존 인프라로 해결되는지 먼저 검증**.

**찬성/반대/중립 판정 부탁**. 특히 **Gemini** 관점에서 중요 — R2/R3에서 "W3-05 포함" 강하게 주장한 입장의 조건부 수용 여부.

### Patch 4 — §1.2 C5 환경 반사 계층에 **renderMask hook** 추가

**Before** (R3):
> `blended += reflection * fresnel * finalAlpha`

**After**:
```glsl
// 기본: 기존 finalAlpha 마스킹 (렌즈 영역에만 반사)
float renderMask = finalAlpha;

// P6-W1 활성화 시: 동공 영역까지 반사 확장 가능
// #ifdef ENABLE_PUPIL_MATERIAL_RESTORE
//   renderMask = max(finalAlpha, smoothstep(iris_radius * 1.2, 0.0, dist));
// #endif

blended += reflection * fresnel * renderMask;
```

**근거**: Patch 3의 P6-W1이 활성화될 때 C5 인프라가 그대로 재사용되게 하는 hook. 현재 W3-05 동작은 기존 finalAlpha와 동일. 추가 런타임 비용 없음 (컴파일 타임 분기).

**찬성/반대/중립 판정 부탁**.

### Patch 5 — 텍스처 크기 공식 기재

**기재 내용**:
```
표준 해상도: 256×256 RGBA PNG
공급 방식: 사용자 측에서 원본(≥1000×1000)을 256×256으로 리사이징하여 SDK에 공급
HIGH tier 옵션: 512×512 (고사양 기기에서 자동 선택)
파일 네이밍: {SKU}_256.png / {SKU}_512.png
```

**근거**:
- 실측 계산: iris 반경 40~150px, 렌즈 영역 120~310px → 256이 최적 (1.28× 다운샘플)
- 512×512은 GPU 텍스처 메모리 1MB/장이라 20 SKU = 20MB, MID tier 버거움
- 1000×1000은 4MB/장 = 80MB, 불채택
- 사용자 직접 리사이징 공급으로 합의

**찬성/반대/중립 판정 부탁**.

## 3. 라운드 종결 조건

- **모든 Patch에 대해 Codex/Gemini 둘 다 hard veto 없음** → 6개 전부 채택, 99_final_decision.md 즉시 수정
- **한 Patch라도 hard veto** → 해당 Patch만 사용자와 재논의, 나머지는 채택
- **응답 자체가 느리거나 실패** → 기본값 "묵시적 찬성"으로 간주하고 30분 후 진행
