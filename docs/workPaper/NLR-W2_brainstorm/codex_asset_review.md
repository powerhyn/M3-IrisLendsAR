# Codex 에셋 축 교차 리뷰 + 비판적 검토 (2026-07-13)

> 대상: 리밸런싱 파이프라인 v4.1 (4-노브 모델·38쌍 실측·재드로잉 판별·하프톤 발견).

## 1. 비판적 검토 결과

### 수용 (핵심 — 전부 v4.2에 반영)

1. **패턴 수렴이 실패를 조용히 통과** [코드 버그]: 출력 패턴비 0.42~1.85 산포. nude-ash-rose 과보정 1.85× **직접 재현 검증 완료**. → k 고정점 반복 → **로그 간격 스캔 + 최근접 선택 + 양방향 수렴 플래그**로 교체.
2. **RGB 잉크색 보정은 림만이 아니라 전역** [측정 누락]: 착색부 전체 알파가중 luma 107→78 (ratio 0.74), 유채 hue 차 ~11.5°. → mid(0.4~0.72)·rim(0.8~1.0) 비율을 각각 실측해 반경 보간 적용.
3. **매칭 마진 검사 부재**: dew-e-dew 2등 점수 0.815(threshold 직하) — 신제품 오매칭 위험. → 1·2등 갭 <0.03 경고 추가.
4. **clamp 무력화**: renorm이 clamp 밖 target으로 농도를 밀어붙임. → 목표 농도를 clamp된 s 기준(`ours×s`)으로 정합.
5. **문서 정정**: "상관 0.18"은 초기 7쌍 기준 — 38쌍 재계산 시 r≈0.33 (결론 "쌍별 재캘리브레이션"은 scale↔원본 음상관 -0.54로 유지). "패턴 +8%"는 기준 의존적 — 농도 감쇠 보정 시 +3.8~12.7%, 하프톤 대역 노치 시 ≈중립. 표현 강등.
6. **재드로잉 "확정" → "α-only 모델 밖" 표현**: 판별 신호(패턴비<0.7)는 지지하되, 변환 표현력 한계·하프톤 오염과 분리 불가하므로 단정 금지.
7. **v5 하프톤은 regular grid 금지**: 3px 정격자는 GPU 확대·회전에서 모아레/셔머링 위험 — blue-noise/void-and-cluster 계열 + premultiplied mipmap + 실기기 A/B 필수. 백로그 조건으로 기록.

### 부분 수용

1. **n=38 독립성 문제 (family bootstrap 권고)**: 지적 타당하나 1인 개발 벤치 보조 분석에 통계 엄밀화는 과함 — "브랜드 클러스터 존재, 효과 크기 위주 해석" 캐비앳으로 기록만.
2. **dear-mellow 포화 23%**: 방향 재현(우리 측정 9.4% — 측정 시점/공간 차이), v4.2 포화율 리포트로 흡수 (24% 출력 확인).

### 거부 (0건)

사실 주장 전건 재현 또는 방향 일치. 림 정책(73→49, 0.282→0.308)은 Codex 재계산이 우리 수치를 독립 확인.
